TLCyzer Web

Auswertung von DC-Platten nach dem GPHF-Minilab-Verfahren, komplett im Browser. Foto laden, Platte zuschneiden, Referenzen zuordnen — Gehalt in Prozent. Das Bild wird nirgends hochgeladen, die Rechnung läuft auf diesem Gerät.

01

Foto der Platte laden

Aufnahme aus der lichtdichten Box unter UV-Beleuchtung, Platte möglichst formatfüllend.

02

Ecken der Platte setzen

Die vier Punkte auf die Plattenecken ziehen. Alles außerhalb wird verworfen, die Perspektive wird entzerrt.

03

Flecken prüfen und Referenzen zuordnen

Fleck antippen zum Auswählen. Nicht erkannte Flecken lassen sich von Hand setzen, Verunreinigungen entfernen.
